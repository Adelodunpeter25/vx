# Project Instructions: VX Editor

## Engineering Standards
- **File Length:** No file should exceed 400 lines of code, with the sole exception of `internal/editor/editor.go`. If a file exceeds this limit, refactor it into smaller, logically grouped files.
- **Architecture:** Keep the modal editing philosophy intact.
- **Keybindings:** Prioritize full keyboard shortcut support.
- **Commits:** Always use single-line commit messages.
- **Builds:** Run `scripts/build.sh` after every significant change or task completion.
